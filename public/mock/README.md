# Тестовый путь маршрута 13

`route-13.geojson` подключён к демо-режиму. Точки четырёх остановок и названия предоставлены пользователем. LineString пока соединяет их по порядку прямыми отрезками и помечен как приблизительный — точная линия дороги ещё не предоставлена.

Формат — GeoJSON FeatureCollection:
- Point для каждой остановки, координаты `[долгота, широта]`.
- Свойства точки: `stop_id`, `name`, `sequence_sample`, `route`.
- LineString для пути: координаты по порядку движения, включая повороты дороги.

После замены файла перезапустите демо-сервер.
